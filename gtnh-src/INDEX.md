## Notes for runtime use (read this)

- **Runtime names on the server are SRG, not MCP.** On an obfuscated (production) Forge server, vanilla and Forge-patched members are named `field_71071_by` / `func_70005_c_`. The sources here show MCP names (`inventory`, `getCommandSenderName`). For reflection, look the name up in `_mappings/members.tsv` (class-aware) or reverse `fields.csv`/`methods.csv`. Class names are already MCP/SRG names at runtime (`net.minecraft.entity.player.EntityPlayer`). Mod classes and members are not obfuscated.
- **SRG names inside string literals were deliberately not remapped.** Reflection calls in decompiled code such as `ObfuscationReflectionHelper.getPrivateValue(TileEntity.class, null, "field_145855_i", "nameToClassMap")` keep the real runtime name.
- **Source is not runtime.** Many mods (hodgepodge, archaicfix, coretweaks, etfuturum, lwjgl3ify, gtnhlib, and others) patch vanilla and other mods at load time with Mixins and ASM. Look at each mod's `mixins.*.json` / `*.refmap.json` and `mixins/` packages before trusting a vanilla method body. The server also starts through lwjgl3ify/RetroFuturaBootstrap (`lwjgl3ify-forgePatches.jar`), which is not decompiled here.
- **Multi-release jars:** for decompiled jars, the highest `META-INF/versions/N` copy of each class was used, because that is what a Java 17+ JVM loads.
- **Shaded libraries dropped (decompiled jars only):** any `.../shadow/`, `.../repack/`, `.../repackage/` package (e.g. Opis' shaded netty/jfree, NEI's antlr, EnderIO's shaded libs, coretweaks' kryo).
- **Kotlin / Scala:** Vineflower wrote `.kt` for Kotlin mods (betterp2p, ThaumcraftResearchTweaks fallback). Scala mods (OpenComputers, ProjectRed, MrTJPCore) come from sources jars as `.scala`.
- **Decompiler gaps:** search for `$VF: Couldn't be decompiled`. That leaves 6 methods in `mods/`, 30 in `_decompiled/` and 1 in `minecraft/` (`FMLProxyPacket`, which needs a client-only constructor).
- **gregtech fallback:** in `_decompiled/gregtech/`, `gregtech/api/enums/ItemList.java` was decompiled with CFR 0.152, because Vineflower needed more than 14 GB for it. `mods/gregtech/` is the real GT5-Unofficial 5.09.54.265 source.
- SRG->MCP remap stats: minecraft/ 82,126 names replaced (25,189 remaining SRG tokens, mostly `p_*` params and members MCP stable_12 never named). Decompiled mods: 191,192 replaced, 8,977 left. `_decompiled/`: 352,061 replaced, 13,088 left. Unmapped names are left as-is.
